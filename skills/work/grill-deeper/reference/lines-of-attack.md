# 攻擊面

六個面。每次選一到兩個，不要全部掃過——那會變成問卷。

**選擇順序**：profile 裡近期含糊的那一類優先，其次是這次的主題最相關的。**一次只攻一個盲點。**

## 1. 機制與對立解釋

- 你相信的因果是什麼？一句「因為 A 所以 B」。
- 同樣的觀察還能被什麼解釋？
- **你的假設和那個對立解釋，會預測不同的東西嗎？** 不會的話，你手上的證據不區分兩者。

第三題是這一面的核心。最常見的失敗是假設和它的反面預測同一件事——「加了 X 效果變好」既符合「X 的機制有效」也符合「X 只是加了容量」。

## 2. 量測與判準

- 主指標是哪一個？只能有一個。
- 什麼結果會讓你說「這條路不通」？
- 重複單位是什麼？（不要把同一次訓練的多次評估當成獨立樣本）
- 判準是在做之前定的還是之後定的？

## 3. 範圍與取捨

- 你**不**做什麼？為什麼那個可以不做？
- 如果只能做一半，砍哪一半？
- 這個方案假設了什麼不會變？

## 4. 依賴與假設

- 這件事成立需要別人先做什麼？他們知道嗎？
- 哪個假設一旦錯了，整件事就垮？
- 有沒有哪個數字是別人給的、而你沒有驗過？

## 5. 失敗模式

- 這件事最可能怎麼失敗？
- 失敗的時候你多久會知道？
- 有沒有一種失敗是「看起來成功但其實沒有」？

最後一題是最有價值的，因為那種失敗不會自己現形。

## 6. 聽眾與交付

- 誰要看？他們已經知道什麼？
- 他們最可能質疑哪一點？
- 講完之後你希望他們做什麼？

## 提案式，不要開放式

已經有 `.grill/context.md` 之後，問題要具體到用上裡面的詞彙：

- 弱：「你的評估怎麼做？」
- 強：「你的 held-out 一樣切在物件實例那一層嗎，還是這次改了？」

第二種能得到決定，第一種只能得到敘述。這是累積知識最直接的回報。

## 什麼時候停

不是問到沒問題可問，是問到**下一個問題不會改變任何行動**為止。

拷問完給一份短的：站得住的地方、需要補的地方、以及本次寫回了什麼。不要重述整段對話。
